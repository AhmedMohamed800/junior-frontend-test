# React Native User List

A React Native mobile application built with Expo, Redux Toolkit, and AsyncStorage for browsing and searching user profiles.

## Features

- 👤 **User Profiles**: View detailed user profile cards.
- 🔍 **Search**: Filter users instantly by name.
- 🔄 **Pagination & Caching**: Fetch paginated data with persistent offline caching via AsyncStorage.
- ⚡ **Performance**: Optimized `FlatList` rendering for smooth scrolling.

## Tech Stack

- **Framework**: Expo (React Native)
- **State Management**: Redux Toolkit
- **Storage**: AsyncStorage
- **Routing**: Expo Router

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Start the App

```bash
npx expo start
```
