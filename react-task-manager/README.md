# Task Manager

A responsive task management application built with React and TypeScript. It allows users to create, edit, delete, search, and filter tasks while keeping data persistent using `localStorage`.

## Features

- Create tasks
- Edit tasks
- Delete tasks with GSAP animations
- Set task priority:
  - Low
  - Medium
  - High
- Set task status:
  - In Progress
  - Completed
- Search tasks by title
- Filter tasks by status and priority
- Persist tasks using `localStorage`
- Synchronize tasks between browser tabs
- Responsive UI
- Form validation

## Tech Stack

- React
- TypeScript
- Redux Toolkit
- Tailwind CSS
- GSAP
- Vite

## Getting Started

### Installation

```bash
npm install
npm run dev
```
